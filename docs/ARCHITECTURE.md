# Architecture

Velune uses React, TypeScript, Vinext and a Cloudflare-compatible Worker build.

The browser renders the terminal, workspace, assistant and vault. Three.js and a canvas fallback render the same fractured emblem. A pure scroll mapping gives each chapter a reading hold before its next transition. The wordmark springs and pointer forces operate on particle geometry.

Server routes retrieve market history and check configured holder access. Wallet connection uses detected EVM providers. Encryption remains inside the browser: PBKDF2-SHA256 with 600,000 iterations derives an AES-256-GCM key; each file receives a random salt and IV. The encrypted container includes authenticated file metadata.

No private proof engine, transaction relay or audited swap router is implemented in this snapshot. The interfaces and implemented cryptography are documented separately from those integrations.
